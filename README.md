# Rental-Mart SaaS Platform

A premium, multi-tenant SaaS platform for streamlined rental management.

## 🚀 Overview
**Rental-Mart** is designed to empower rental businesses with professional-grade tools for tracking inventory, managing orders, and analyzing performance. Built with a focus on visual excellence and intuitive user experience.

## 🛠️ Tech Stack
- **Frontend**: React 19 + Vite
- **State Management**: Zustand
- **Routing**: React Router 7
- **Styling**: Vanilla CSS (Global Design System)
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 📂 Project Structure
- `/frontend`: React application source code.
- `/docs`: Comprehensive project documentation and reference images.
- `.agents/rules`: Custom AI agent operating guidelines.

## 🏁 Getting Started
1. Navigate to `/frontend`.
2. Install dependencies: `npm install`.
3. Run development server: `npm run dev`.
