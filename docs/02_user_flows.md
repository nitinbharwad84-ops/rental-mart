# User Flows

## 1. Authentication Flow
1. **Landing**: User arrives at the login page.
2. **Registration**: 
    - User clicks "Register here".
    - Navigates to Registration Page.
    - Fills in Name, Email, Phone, Password, and Confirm Password.
    - Password meter provides visual feedback.
    - User clicks "SIGN IN" (Register button in this context).
    - Redirected back to Login or directly to Dashboard.
3. **Login**:
    - User enters Email and Password.
    - Clicks "SIGN IN".
    - Redirected to the Dashboard.

## 2. Dashboard Navigation Flow
1. **Sidebar Interaction**:
    - User clicks "Rental" -> Navigates to Rental management view.
    - User clicks "Products" -> Navigates to Products view (Placeholder).
    - User clicks "Reporting" -> Navigates to Reporting view (Placeholder).
2. **Profile Access**:
    - User clicks on profile name/avatar in the top right to access settings.

## 3. Rental Management Flow
1. **Status Filtering**:
    - User clicks "Quotation" tab -> List filters to show only Quotation orders.
    - User clicks "Reserved" tab -> List filters to show only Reserved orders.
    - User clicks "All" -> List resets to show everything.
2. **Searching**:
    - User types "Customer1" in the search bar.
    - List updates in real-time to show matches.
3. **Order Interaction**:
    - User clicks "Create" -> Navigates to create new rental order (Placeholder).
    - User clicks an existing order -> Navigates to order details (Placeholder).

## 4. Mobile Flow
1. **Responsive Sidebar**:
    - On mobile, the sidebar collapses into a hamburger menu or bottom navigation bar.
2. **List Optimization**:
    - Rental list items stack or use a simplified card view for narrow screens.
